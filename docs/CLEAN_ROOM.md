# Clean-room development policy

Implement requirements from independently written specifications, public mathematical formulations, published open formats and documented open-source APIs. Record the source and license of any external code or dataset incorporated into the project.

The current implementation was authored independently from the Gmsh public API and CalculiX's documented input/output interfaces. The bar geometry is generated here. No Ansys source, decompiled output, binaries, installation files, logos, licensed models or proprietary assets are included or used to generate the solver.

REA is an optional, separate research tool. Its installation does not authorize analysis of a proprietary product. If future behavior research is proposed, define the permitted target, authorization and evidence boundary before research begins. Keep proprietary implementation evidence outside this source tree. Implementers should work from independently authored functional specifications and public references. Do not bypass licensing or access controls.

Before publishing a release, include the required notices and corresponding-source arrangements for any third-party binaries actually distributed. A download URL alone is not a substitute for reviewing applicable distribution obligations. The source repository excludes installed tool binaries and environments.
